Cómo recorrer los espacios

Selecciona una estancia o la clínica completa. Usa Perspectiva, Planta y Girar vista para cambiar el punto de vista. Arrastra sobre el modelo para girarlo y pellizca con dos dedos para acercar o alejar; también puedes usar los botones + y −.

Activa o desactiva las paredes y elige una puerta para abrirla o cerrarla. Para desplazarte por esta página en móvil, desliza fuera del modelo.

Con teclado, usa Tab para recorrer los controles. Dentro del modelo, las flechas giran la vista y + y − cambian el zoom.
