# Web Clínica Dental Doctor Babío

Primera versión de una web estática orientada a captar pacientes de implantes en Sevilla.

## Estructura actual

- `index.html`: portada y mensaje principal
- `implantes-carga-inmediata-sevilla.html`
- `implantes-sector-estetico-sevilla.html`
- `implantes-fracasados-sevilla.html`
- `contacto.html`
- `styles.css`
- `script.js`
- `robots.txt`

## Pendiente antes de publicar

- Definir el dominio final.
- Añadir `sitemap.xml` con URLs absolutas del dominio definitivo.
- Añadir enlaces reales a reseñas, WhatsApp o formulario si se quiere captar por más vías.
- Sustituir o ampliar el contenido con fotos reales de la clínica.
- Añadir páginas legales si la web va a publicarse: aviso legal, privacidad y cookies.
